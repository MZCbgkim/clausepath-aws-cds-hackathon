## 개선 우선순위 (여러 페르소나가 겹쳐 지적한 것 위주, 코드로 확인함)
### 여행자 화면
1. **P0 전송 실패 복구 없음** — `post()`에 네트워크 오류 처리가 없고 입력창·사진을 먼저 비움 (확인됨). 실패 시 복원 + "다시 보내기", 오프라인 배너.
2. **P0 진짜 보험사인지 확인할 표시 없음 (스미싱 우려)** — 문자·첫 화면에 보험사 이름, 대표번호, 증권 끝자리. "전화로 확인" 버튼.
3. **P0 보안 페이지** — 390px에서 입력칸이 넘침, 은행·계좌 자유 입력, 미국 routing number 없음, "(데모…)" 문구, 제출 후 안내 없음.
4. **P1 조항 코드·영어 노출** — 진행 과정의 `TD-3 · PLAN-2`, `unreadable`, `cancelled · Typhoon Hagi`. 조항 이름과 한국어로 표시.
5. **P1 남은 서류·제출 버튼·진행 상태가 채팅에 없음** — 헤더 진행 막대에 라벨 없음, "submit"을 직접 쳐야 함. 체크리스트 시트 + "보험사에 제출하기" 버튼 + 제출 후 상태.
6. **P1 글자 크기·가로 넘침** — px 고정(11.5~13px), 원문 보기 가로 스크롤. rem·최소 16px, 원문 폭 맞춤.
7. **P1 "얼마 받나"** — 영수증 USD 환산, 하루/여행 한도 대비 남은 금액(현재는 심사 패킷에만 있음).
8. **P2 "📎×3 [attachment]"** — 보낸 사진 썸네일, 재촬영 사진 표시. 사람 상담 연결 버튼.

### 보험사 화면
1. **P0 대시보드가 5초마다 상세를 통째로 다시 그림** — 메모 입력이 지워짐 (확인됨: `setInterval → openClaim`). 입력 중 갱신 중지, 변경분만 갱신.
2. **P0 권한·위험 버튼** — 누구나 승인·대량 알림 가능, "결항·지연 발생"(실제 SMS 발송)과 "데모 페르소나"가 같은 줄, 확인 단계 없음. 역할 분리(Cognito 그룹), 발송 전 대상 수·문안·비용 확인.
3. **P0 체크리스트 신뢰** — 심사 패킷은 판독 불가 영수증이 있어도 6개 모두 ✓, 대시보드는 결항 확인서로 "원래 항공권"을 채웠는데(의도된 규칙) 근거 표시가 없음. 항목별 근거 서류 링크, 받음/검증됨/보완 필요 3단계.
4. **P0 검색·필터 없음** — 이름·전화 뒷자리·청구번호 검색, 상태 필터, 동명이인 구분(증권번호·전화 마스킹).
5. **P1 메모와 고객 메시지 혼동** — 입력란 하나로 내부 메모·고객 발송을 겸함, 발송 미리보기 없음.
6. **P1 결정 기능** — 부지급·감액, 지급액, 근거 조항 선택, 통지문 초안, 날짜별 한도 산정표·환율 표시, 코어 시스템용 내보내기.
7. **P1 언어** — 한국어 화면인데 보장 판단 본문·패킷이 영어, `likely_covered` 코드값 노출.
8. **P1 운영** — KPI·SLA, AI 판단 품질(심사자 번복률), 감사 로그 화면, 약관 버전 관리, 고객에게 간 SMS 원문 타임라인, 보존 정책(RemovalPolicy.DESTROY).
